Como garantir que funcione?

  1. Conexão na mesma rede WiFi: O celular e o computador precisam estar no mesmo roteador (WiFi: 192.168.3.x).
  2. Servidor em Modo Host: Se o QR code falhar, reinicie o servidor no computador expondo o IP na rede com o comando: 
    npm run dev -- --host
  3. Liberar o Firewall: Certifique-se de que o Windows Defender ou o antivírus não esteja bloqueando conexões de rede locais na porta 5173.
